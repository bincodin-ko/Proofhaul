# 계산 규칙 v2026 — 원문 대조 전 초안

## 경고

**아래 내용은 언론 보도와 2차 자료에서 정리한 것이다. 코드로 옮기기 전에 반드시 원문과 대조할 것.**

숫자 하나가 틀리면 제품 전체의 신뢰가 무너진다. 이 문서를 "확정"으로 바꾸기 전에는 계산 로직을 작성하지 않는다.

## 확인된 사실 (비교적 신뢰도 높음)

- 적용 품목: **수출입 컨테이너, 시멘트 2종뿐**
- 시행 기간: 2026.1.1 ~ 2028.12.31 (3년 한시)
- 2026년 요율: 2026.1.30 고시 확정, **2026.2.1 ~ 12.31 효력**
- 연중 개정 발생: **2026.8.1 유가 연동으로 컨테이너 운임 인상**
- 운임은 두 종류
  - **안전운송운임** — 화주가 운수사업자에게 지급해야 하는 최저 운임
  - **안전위탁운임** — 운수사업자가 화물차주에게 지급해야 하는 최저 운임
- 화주가 안전운송운임보다 적게 지급하면 **과태료 500만원**
- 안전운임보다 낮은 운임·미지급 사례를 접수하는 **안전운임신고센터** 운영 중

## 초안 항목 — 출처별로 구분

이 절은 두 부분으로 나뉜다. **아래쪽(B)은 근거 문서를 확인하지 못한 것이므로, 원문에서 다시 채우는 것이 원칙이다.**

### A. 2차 자료에서 근거 문장을 확인한 항목

기사·해설에서 해당 내용을 직접 읽었다. 그래도 원문 대조는 해야 한다.

- `[ ]` 할증은 단순 합산이 아닌 **가산 방식**
- `[ ]` 시멘트는 최대 상한 **150%**. 계산 결과가 초과해도 150%까지만 인정
- `[ ]` 냉동·냉장: 운수사업자가 **발전기 부착 샤시 제공** 시 안전위탁운임 할증 30%의 절반인 **15% 추가**
- `[ ]` 발전기 부착 시 **장치 가동 여부와 무관**하게 적용
- `[ ]` **상·하행 공(空)컨테이너 운송에는 미적용**
- `[ ]` 중량은 **선하증권(B/L) 기재 중량 우선**, 없으면 **계근 중량**
- `[ ]` 복화(컨테이너): 수입·수출 배차를 조정해 왕복 모두 적재 상태(Full)로 운송
- `[ ]` 복화(시멘트): **동일 화주가 동일 구간**을 운송하는 형태
- `[ ]` 유가 연동: 3개월 평균 유가가 직전 산정 기준 대비 **±50원 이상** 변동할 때만 반영
- `[ ]` 유가 연동: 1분기 평균이 기준을 넘으면 **5~7월 운임에 적용**
- `[ ]` 안전운송운임에는 안전위탁운임 할증으로 추가된 금액만큼을 동일하게 합산

### B. 근거를 확인하지 못한 항목 — 숫자를 쓰지 말고 원문에서 채울 것

아래는 **출처를 특정하지 못했다.** 기억이나 일반적 통념에서 나온 값일 수 있다. 빈칸으로 두고 원문에서 직접 옮겨 적는다.

- `[ ]` 대기료 기산 기준 (컨테이너 규격별 몇 시간 초과부터인가) → **원문에서 확인**
- `[ ]` 대기료 기산점 (도착 시각인지 접수 시각인지), 초과분 계산 단위
- `[ ]` 시간 관련 할증(공휴일·심야 등)의 정확한 적용 방식과 비율 → **원문에서 확인**
- `[ ]` 검색대 통과 등 개별 부대비용 금액 → **원문에서 확인**
- `[ ]` 험로·오지 할증 기준 구간 정의
- `[ ]` 세척·손상 교체 확인서 발급 요건
- `[ ]` 반올림 규칙, 경계값 처리 (정각 도달 시 포함 여부)

### C. 표준 서식

- `[ ]` 대기시간 확인서
- `[ ]` 험로·오지 확인서
- `[ ]` 컨테이너 세척·손상 교체 확인서
- `[ ]` 각 서식의 **필수 기재 항목** — 우리 PDF가 이걸 다 담아야 한다
- `[ ]` 화주는 차주의 확인서 서명 요청을 받으면 차량 입·출입 시간에 따라 서명해야 하는 의무 조항

## 코드 반영 규칙

1. 확정된 항목만 `rules/v2026-02.ts`, `rules/v2026-08.ts`에 넣는다
2. **B절 항목은 원문 확인 전까지 코드에 어떤 숫자도 넣지 않는다.** 초안의 값을 임시로 써두는 것도 금지 — 임시값은 반드시 잊어버린다
3. 대조 못 한 항목은 **구현하지 않는다.** 화면에 "미지원"으로 표시하는 게 틀린 값을 내는 것보다 낫다
4. 모든 계산 함수는 `(input, version) => result` 형태. 버전을 인자로 받는다
5. 규칙 파일마다 상단에 **출처 문서명과 확인 날짜**를 주석으로 남긴다
6. 예외가 너무 많아 코드로 못 옮기겠다면 그건 신호다. `00-PLAN.md`의 중단 기준을 보라
