# 레이어별 후보 카탈로그

> **경고: 이 파일의 숫자는 이미 틀렸을 가능성이 높다.**
> 후보 이름과 "무엇을 보는가"를 얻는 용도로만 쓰고, **숫자는 한 개도 그대로 옮기지 않는다.**
> 실제 사례: 이 카탈로그는 Hetzner를 "€3.79/월, 가성비 최고"로 적어두었으나, 2026년 4월 37% · 6월 최대 3.1배 인상으로 CX22 계열은 판매 중단됐다. 검색 없이 그대로 썼다면 추천 전체가 틀렸을 것이다.
> 가격이 바뀐 것을 확인하면 이 파일을 갱신해 다음 사용자가 같은 함정에 빠지지 않게 한다.

각 후보 옆의 표기:
- 💰 상한 설정 가능 여부 (예측 가능성)
- 🇰🇷 한국 조건 (서울 리전, 카카오 로그인, 국내 사업자 사용 가능 등)

### 후보에서 빼는 것
AWS ECS/EKS, GCP GKE, Cloud Run 이외의 GCP 조합, 멀티리전, Kubernetes 일체. 1인 규모에서 예측 불가 청구서와 운영 시간 양쪽에서 진다. Cloud Run은 scale-to-zero와 상한 설정이 되므로 예외적으로 후보 가능.

## 9. CI/CD·DNS·CDN·도메인

- **GitHub Actions**: 비공개 레포 월 2,000분 무료. 대부분 충분
- **Cloudflare (무료)**: DNS·CDN·WAF·봇 차단. 호스팅이 어디든 앞에 둔다. 🇰🇷 서울 PoP
- **도메인**: Cloudflare Registrar(원가), Porkbun. 🇰🇷 **.kr/.co.kr은 국내 등록업체(가비아·후이즈 등)** 필요. ⚠️ 첫해 할인이 아닌 갱신가로 계산

## 10. LLM API

기억으로 단가를 쓰지 않는다. 공식 가격 페이지 확인. `claude-api` 스킬이 있으면 참조.
확인할 것: 입력·출력 토큰 단가, 프롬프트 캐싱 할인, 배치 API 할인, 작은 모델로 라우팅 가능한 기능 비율.
계산 단위: **고객 1명당 월 원가.** 이게 객단가의 30%를 넘으면 인프라 문제가 아니라 제품 구조 문제다.

## 11. 규모별 기본 조합 (출발점 — 프로필로 반드시 조정)

**A. 파일 적고 트래픽 낮은 B2B SaaS, 한국 사용자, 정지 내성 낮음**
Vultr 서울 또는 Lightsail 서울 + Coolify + Postgres(같은 박스) + R2 + 자체 인증 + Resend + pg-boss + Sentry/UptimeRobot + Cloudflare 앞단
→ 월 현금 $10~20, 운영 시간 월 2~4시간

**B. 같은 조건, 정지 내성 높음(밤에 죽으면 사업 문제) → 관리형**
Cloudflare Workers 또는 Vercel Pro + Supabase Pro(서울) + R2 + Supabase Auth + Resend + Cloudflare 앞단
→ 월 현금 $30~50, 운영 시간 월 1시간 이하

**C. 파일·이미지 다운로드가 핵심**
어떤 호스팅이든 **R2/B2 + Cloudflare CDN**이 중심. 호스팅은 A 또는 B에서 고른다. 이미지 변환은 업로드 시점 처리.

**D. LLM·PDF 등 장시간 작업 중심**
상시 실행 서버(VPS 또는 Fly machine) + 큐. 서버리스 단독은 후보 아님.

**E. 글로벌 우선, 한국은 나중**
Cloudflare 스택(Workers + D1/Neon + R2) 또는 Fly.io 멀티리전(나중에). 결제는 MoR.
