# 현업 조사 방법

목적은 "무엇이 유명한가"가 아니라 **"우리 규모의 사람들이 실제로 돈을 내고 쓰면서 뭐라고 하는가"**를 확인하는 것이다. 가격표는 마케팅이고, 청구서 공유 글과 이전 후기가 증거다.

## 기억 금지 규칙

모델이 기억하는 가격은 학습 시점의 것이고, 이 업계는 12개월 안에 요금제를 바꾼다. 아래는 **검색으로 확인하기 전에는 보고서에 쓰지 않는다.**
- 월 요금, 포함량, 초과 단가
- 무료 티어의 존재 여부와 상업 사용 허용 여부
- 리전 목록 (서울·도쿄·싱가포르 유무)
- 서비스가 아직 살아 있는지, 인수·종료·정책 변경이 있었는지

확인한 값은 `URL + 확인 날짜 + 인용한 숫자`로 기록한다. 보고서의 모든 숫자는 이 기록으로 추적 가능해야 한다.

## 검색 순서 — 비용 유출 지점부터

프로필에서 지목한 유출 지점(egress, 이미지 변환, 장시간 실행, DB 연결, LLM 토큰, 알림톡)을 가장 잘 막는 후보를 먼저 찾고, 그 후보를 중심으로 나머지 레이어를 맞춘다. 호스팅부터 고르고 스토리지를 끼워 맞추면 보통 egress에서 진다.

## 쿼리 패턴

영어와 한국어 둘 다 돌린다. 한국어 결과에는 리전·결제·알림톡 같은 국내 조건이 들어 있고, 영어 결과에는 규모별 청구서 사례가 많다.

**가격 현재값 확인**
- `<서비스> pricing` → 공식 페이지. 가격표에 "included", "overage", "per seat"를 찾는다
- `<서비스> pricing change 2026`, `<서비스> 가격 인상`
- `<서비스> free tier commercial use` — Hobby/Free 약관에 "non-commercial", "personal" 문구가 있는지

**실제 사용자 증거**
- `<서비스> bill`, `<서비스> "our bill"`, `<서비스> 청구서`, `<서비스> 요금 폭탄`
- `moved from <A> to <B>`, `migrated off <A>`, `<A>에서 <B>로 이전`
- `<A> vs <B> 2026 site:news.ycombinator.com`, `<A> vs <B> reddit`
- `<서비스> indie hacker`, `<서비스> solo founder`, `<서비스> 1인 개발`

**생존·정책 확인**
- `<서비스> sunset`, `<서비스> acquired`, `<서비스> shutting down`, `<서비스> 서비스 종료`
- `<서비스> status incidents` — 최근 6개월 장애 빈도

**한국 조건**
- `<서비스> seoul region`, `<서비스> 한국 리전`, `<서비스> latency korea`
- `<인증 서비스> kakao login`, `<인증 서비스> 카카오 로그인`
- `알림톡 API 단가 2026`, `알림톡 대행사 비교`
- `토스페이먼츠 수수료`, `<MoR> korea`, `한국 사업자 stripe` (국내 법인은 Stripe 직접 사용 불가 — 재확인)

## 소스 신뢰도 (위가 더 믿을 만하다)

1. **공식 가격 페이지·문서·약관** — 숫자는 여기서만 가져온다
2. **청구서를 공개한 글** — 금액과 사용량이 같이 적힌 것. HN, Reddit, 개인 블로그, GeekNews, 디스콰이엇
3. **이전(migration) 후기** — 왜 옮겼는지, 옮긴 뒤 얼마가 됐는지가 있는 것
4. **가격 변경 발표 스레드의 반응** — 어떤 사용자층이 떠났는지 보인다
5. **비교 글·유튜브** — 참고만. 대개 제휴 링크이거나 무료 티어만 써본 것
6. **서비스 공식 블로그의 고객 사례** — 증거 아님. 선별된 성공담이다

우리 규모(1~2인, 월 매출 1만 달러 이하)의 사례만 증거로 친다. 시리즈 B 스타트업이 Kubernetes로 옮긴 글은 우리 질문에 답하지 않는다.

## 후보마다 반드시 기록할 3가지

| 항목 | 왜 |
|---|---|
| 무료 티어 상업 사용 가능? | Vercel Hobby처럼 약관상 금지면 첫 결제 순간 유료로 강제된다 |
| 최근 12개월 가격·정책 변경 | 최근 바뀐 곳은 또 바뀐다. 무료 티어 폐지 이력은 특히 |
| 한국 리전 또는 지연 | 서울 없음 → 도쿄(~30ms)·싱가포르(~70ms)·미국 서부(~130ms)·유럽(~250ms). DB가 멀면 페이지당 쿼리 수만큼 곱해진다 |

## 검색이 막혔을 때

WebSearch/WebFetch가 없거나 실패하면 `candidates.md`의 값을 쓰되, 보고서에 **"미검증 — 학습 시점 기억값"**이라고 표시하고 사용자에게 계약 전 재확인을 요청한다. 검증 못 한 숫자를 검증한 것처럼 쓰는 것이 이 스킬의 가장 큰 실패다.

## 조사 종료 조건

- 각 레이어에 후보 2~3개, 각 후보에 3가지 기록이 채워짐
- 비용 유출 지점에 대해 "실제 청구서" 수준의 증거가 최소 1개
- 주 스택의 모든 숫자에 URL이 붙음

이 조건이 안 채워졌는데 시간이 부족하면, 채워진 부분만으로 추천하되 **어느 숫자가 미검증인지 보고서에 표시**한다.
