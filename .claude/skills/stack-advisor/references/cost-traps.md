# 비용 함정 목록

Phase 0에서 프로필과 대조해 **이 서비스에 해당하는 것**만 골라낸다. 청구서의 80%는 이 중 한두 개에서 나온다. 각 항목에 "이 서비스에 해당하는가"를 답하고, 해당하면 후보 선택의 1순위 기준이 된다.

## 1. Egress — 나가는 트래픽 과금
파일 다운로드·이미지 서빙이 많은 서비스의 청구서 1위. S3 계열은 GB당 과금(서울 리전은 더 비쌈), Vercel은 포함량 초과분 과금, Supabase도 포함량 초과 시 과금.
- **해당 조건**: 사용자가 파일·이미지·영상을 내려받는다, 공개 페이지에 이미지가 많다
- **방어**: egress 무료 스토리지(Cloudflare R2, Backblaze B2)에 파일을 두고 CDN(Cloudflare) 뒤에 둔다. 호스팅과 무관하게 이것만으로 구조가 바뀐다

## 2. 이미지 최적화 변환 과금
Next.js `<Image>`를 Vercel에서 쓰면 변환(transformation) 단위로 과금된다. UGC 이미지가 많으면 예측이 안 된다.
- **해당 조건**: 사용자 업로드 이미지를 여러 크기로 보여준다
- **방어**: 업로드 시점에 리사이즈해 저장(sharp), 또는 Cloudflare Images / 자체 이미지 프록시. `unoptimized` 옵션으로 변환 자체를 끄는 것도 답

## 3. 서버리스 실행 시간 — 기다리는 시간도 돈
서버리스 함수는 **응답을 기다리는 동안도** 과금된다. LLM 스트리밍 30초, 외부 API 대기, PDF 생성이 여기 걸린다.
- **해당 조건**: LLM 호출, PDF·이미지·영상 처리, 느린 외부 API
- **방어**: 장시간 작업은 서버리스에서 빼서 상시 실행 서버(VPS, Fly machine)나 큐+워커로. 서버리스를 유지한다면 "fluid compute" 같은 대기 시간 비과금 옵션이 있는지 확인

## 4. DB 연결 수 — 서버리스 + Postgres 조합의 고전적 사고
함수 하나당 연결 하나를 열면 트래픽이 조금만 튀어도 연결 한도에 걸린다. 큰 인스턴스로 올리는 게 답이 아니다.
- **해당 조건**: 서버리스/엣지 호스팅 + 관계형 DB
- **방어**: 연결 풀러 필수 (Supabase Supavisor, Neon pooler, PgBouncer). 후보 DB가 풀러를 기본 제공하는지 확인

## 5. 무료 DB 자동 정지·콜드 스타트
Supabase 무료 프로젝트는 일정 기간 미사용 시 일시정지, Neon 무료는 scale-to-zero 후 첫 요청이 느리다. 데모 시연 중 "로딩 중…"이 뜨는 게 이것이다.
- **방어**: 출시 후 첫 유료 고객이 생기면 DB부터 유료로 올린다. 비용표에 유료 가격을 병기하는 이유

## 6. 무료 티어 소멸 이력
Heroku(2022), Railway(2023), PlanetScale(2024)은 무료 티어를 없앴고, Render 무료 DB는 기한이 있다. Oracle Always Free는 용량 부족으로 인스턴스 생성이 막히거나 계정이 회수된 사례가 반복 보고된다.
- **원칙**: 무료 티어에 **데이터 층**(DB, 스토리지)을 올리지 않거나, 올리더라도 백업이 다른 곳에 있어야 한다

## 7. 상한 없는 종량제
AWS/GCP 예산 알림은 **알림**이지 차단이 아니다. 잘못된 재귀 호출, 크롤러 봇, DDoS 하나가 한 달치 매출을 청구서로 바꾼다.
- **방어**: 지출 상한(spend cap/limit) 설정이 있는 서비스를 우선. 없는 서비스는 후보에서 감점하고, 쓸 거면 알림을 매일 기준으로 건다

## 8. 좌석(seat) 과금
Vercel·Netlify 등은 팀 멤버당 월 요금이다. 협업자 한 명 초대가 요금 2배. 외주 개발자에게 잠깐 권한 주는 것도 한 달 요금
- **방어**: 좌석 과금 서비스는 1인 기준으로 계산하고, 협업 시나리오가 있으면 그 비용을 미리 적는다

## 9. MAU 절벽 — 인증 서비스
Clerk·Auth0 류는 무료 MAU를 넘는 순간 요금이 계단식으로 뛴다. 무료 사용자가 많고 유료 전환율이 낮은 서비스(프리미엄 모델)에서 치명적.
- **해당 조건**: 무료 회원가입이 열려 있고 유료 전환율이 10% 미만
- **방어**: MAU 기준이 아닌 인증(Supabase Auth, 자체 구현 라이브러리)을 우선. 카카오·네이버 로그인 지원 여부도 여기서 같이 확인

## 10. 로그·에러·모니터링 ingest 폭발
에러 루프 하나가 하루에 Sentry 월 쿼터를 다 쓴다. 로그를 전부 외부로 보내면 트래픽보다 로그 비용이 먼저 커진다.
- **방어**: 에러 샘플링·rate limit 설정, 로그는 로컬 파일+로테이션이 기본. Datadog 계열은 이 규모에서 후보 자체가 아니다

## 11. LLM 토큰
인프라보다 먼저 200달러를 뚫는 항목. 재시도 루프, 긴 시스템 프롬프트 반복 전송, 캐싱 미적용, 필요 이상 큰 모델.
- **해당 조건**: LLM 기능이 있음
- **방어**: 고객 1명당 월 토큰 원가를 먼저 계산. 프롬프트 캐싱·배치 API·작은 모델 라우팅 확인. 원가가 객단가의 30%를 넘으면 기능 구조를 바꾼다

## 12. 알림톡·SMS
건당 단가는 낮아 보이지만 발송량 × 재시도 × 실패 시 SMS 대체 발송이 곱해진다. 발신번호 사전등록, 템플릿 심사 지연 같은 시간 비용도 있다.
- **방어**: 발송 트리거를 "고객이 원하는 것"으로 제한하고, 실패 시 SMS 대체를 기본 켜지 않는다. 대행사별 단가와 최소 충전금 비교

## 13. 도메인 첫해 할인
첫해 1,000원, 갱신 4만원. .kr/.co.kr과 .com/.io/.ai의 갱신가는 크게 다르다.
- **방어**: 갱신가 기준으로 계산. .io·.ai는 갱신가가 특히 높다

## 14. 백업 — 안 해서 생기는 비용
셀프호스트 DB의 백업 부재는 비용이 0원이 아니라 사업 종료 확률이다. 관리형의 "백업 포함"이 실제로 시점 복구(PITR)인지, 일일 스냅샷인지 구분한다.
- **방어**: 셀프호스트면 매일 덤프를 다른 제공자의 스토리지(R2/B2)로. 이 작업 시간을 운영 시간에 넣는다

## 15. 한국 사업자의 해외 SaaS 결제
해외 서비스는 세금계산서가 없다(비용 처리는 인보이스+카드 명세). 국내 서비스는 VAT 별도 표시가 많아 표시가에 10%를 더해야 비교가 된다. 환율 변동도 달러 결제 비용에 그대로 반영된다.
- **방어**: 비교표는 부가세 포함 원화로 통일. 세무 처리는 세무사 확인 사항으로 표시

## 16. 부품 수 자체
서비스 8개면 청구서 8개, 대시보드 8개, 장애 지점 8개, 각각의 가격 변경 리스크 8개. 각 부품이 싸도 합치면 운영 시간이 늘어난다.
- **방어**: 같은 일을 하면 부품이 적은 조합을 우선. "이 부품이 없으면 무엇이 안 되는가"에 답 못 하면 뺀다
