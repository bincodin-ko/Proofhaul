# 스킬 수정본 보관소

claude.ai의 스킬을 고친 내용을 여기 둔다.

이유가 있다. 작업 환경의 `~/.claude/skills/synced/`는 **동기화될 때 통째로 덮어써진다.**
거기서 고친 것은 남지 않는다. 그래서 고친 내용을 저장소에 같이 둔다.

## 쓰는 법

1. 아래 파일을 연다
2. 전체를 복사한다
3. claude.ai → 설정 → 스킬(Skills) → 해당 스킬 → 내용을 붙여넣어 덮어쓴다

덮어쓰기 전까지 이 수정은 **이 대화에서만** 적용된다.

## 파일

| 파일 | 원래 스킬 | 왜 고쳤나 |
|---|---|---|
| `solo-biz-idea-finder.md` | `anthropic-skills:solo-biz-idea-finder` | 경쟁 조사를 웹 검색만으로 하고 있었다. 현장 직군 제품은 웹에 흔적이 없고 **앱스토어에만** 있어서, 설치 수 수만 건짜리 경쟁자를 통째로 놓친다. 앱스토어 조사를 필수 절차로 넣었다 |
| `stack-advisor.md` | `anthropic-skills:stack-advisor` | 고객이 0명인 시점에도 100명 기준 인프라를 추천했다. "지금 얼마인가"를 먼저 보도록 고쳤다 |
