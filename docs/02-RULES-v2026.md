### 해결되지 않은 경계값 — 구현 시 서식을 따른다

**조항 본문과 별지 서식의 종료 시점 정의가 다르다.**

- 조항 24. 본문: 종료 = "상·하차 **및 송장발급을** 완료한 시간"
- 별지 제4호서식 참고란: `출차시각` = "상·하차 완료 후 **운행시작** 시각"

송장발급 시간이 서식에는 없다. **우리는 서식을 따른다** — 실제 증빙물이 서식이기 때문이다.
화면에 주석을 남기고, 계산은 하지 않는다(아래 "계산하지 않는다" 참조).

정각 도달 시 포함 여부, 30분 미만 잔여분 처리는 **원문에 규정이 없다.** 임의 반올림 금지.

### 제품 반영

1. 서명 화면에 **근거 조항을 표시한다.** 예: `2026년 적용 화물자동차 안전운임 고시 별표 1 24.다.`
2. "전자문서 포함"이 원문에 있으므로 **종이 대체 가능성을 우리가 주장할 필요가 없다.** 고시가 직접 인정한다
3. 서명을 요구한 사실과 시각을 기록한다. 의무 조항이 있으므로 **무응답 기록 자체가 증거력을 갖는다**
4. 험로·오지 확인서(제3호·제5호)에는 서명 의무 조항이 **없다.** 같은 문구를 쓰면 안 된다

## 계산하지 않는다 — 그대로 유지

원문을 확보했지만 **대기료 금액 계산은 여전히 하지 않는다.** 이유가 바뀌었다.

이전 이유: 기준을 몰라서
현재 이유: **기준은 알지만, 분쟁의 쟁점이 금액이 아니라 시각이기 때문이다**

- 기산 시작이 "화주의 **도착요청시간**"이다. 이건 화주만 아는 값이고, 별지 제4호서식에도 `입차요청시각(화주)` 로 따로 들어간다. 우리가 추정할 수 없다
- 정각 처리·잔여분 처리 규정이 원문에 없다. 우리가 정하면 그건 우리 규칙이지 고시가 아니다
- 금액을 우리가 제시하면 **틀렸을 때 책임이 우리에게 온다.** 시각만 기록하면 그 책임이 없다

화면에는 시각 3개(`입차요청시각` / `입차시각` / `출차시각`)와 그 차이(분)까지만 표시한다.
금액은 **"기준: 항만부두 1시간 초과 시 30분당 20,000원 (별표1 24.가)"** 처럼 **근거만 안내**하고 곱셈은 하지 않는다.

## 코드 반영 규칙

1. 확정된 항목만 `rules/v2026-02.ts`, `rules/v2026-08.ts`에 넣는다
2. 조항 번호를 주석으로 병기하지 않은 값은 넣지 않는다
3. 대조하지 못한 항목은 **구현하지 않는다.** 화면에 "미지원"으로 표시하는 게 틀린 값을 내는 것보다 낫다
4. 모든 계산 함수는 `(input, version) => result` 형태. 버전을 인자로 받는다
5. 규칙 파일 상단에 **출처 문서명(국토교통부고시 제2026-55호)과 확인 날짜(2026-09-19)**를 주석으로 남긴다
6. 예외가 너무 많아 코드로 못 옮기겠다면 그건 신호다. `00-PLAN.md`의 중단 기준을 보라
