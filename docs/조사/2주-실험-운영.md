## 1-1. 등업 — 여기서 일주일이 먼저 나간다

### 내가 확인하지 못한 것

카페 내부는 로그인해야 보이고, **이 작업 환경은 `cafe.daum.net`·`cafe.naver.com` 접속이 막혀 있다.** 그래서 로드파일럿·화물마루의 **실제 등업 조건을 확인하지 못했다.** 아래는 국내 카페의 일반적인 구조이고, 정확한 조건은 가입 직후 카페 공지에서 직접 봐야 한다.

### 보통 이런 것들이 걸린다

- 가입 기간 **7일 이상**
- 방문 횟수 **5~10회** (하루 1회만 세는 곳이 많다 — 몰아서 못 채운다)
- 게시글 **3개** 또는 댓글 **10개**
- **가입인사** 게시판에 양식대로 글 1개
- 출석체크 게시판 며칠

### 가입 직후 5분 안에 확인할 것

1. 좌측 메뉴의 **`등업 게시판`** / `정회원 신청` / `카페 공지`
2. 거기 적힌 **숫자를 그대로 적어 온다** — 날짜 · 방문 · 글 · 댓글
3. **준회원이 글을 쓸 수 있는 게시판이 따로 있는지** — 있는 카페가 많고, 있으면 7일을 기다릴 필요가 없다

### 경고 — 등업 조건 채우려고 아무 댓글이나 달면 안 된다

"좋은 정보 감사합니다" 같은 댓글 10개는 운영자가 한 번에 알아본다. **홍보 계정으로 찍히면 글을 쓰자마자 삭제되고 강퇴당한다.** 실험이 시작도 못 하고 끝난다.

### 대신 — 기다리는 7일을 조사로 쓴다

등업 기간은 낭비가 아니다. **가장 싼 고객 조사 기간이다.**

매일 10분:

1. 카페에서 `대기료` `대기시간` `인수증` `부대비용` `안전운임` 으로 검색한다
2. 나오는 글과 댓글을 읽는다
3. **쓸 만한 문장을 그대로 메모한다** — 그 바닥 말투로 1회차 글을 써야 한다
4. **진짜 도움이 되는 답글만 단다.** 아는 게 있으면 답하고, 없으면 안 단다

7일 뒤에 남는 것:

- 등업
- 1회차 글을 **그들의 말로** 쓸 재료
- **이미 대기료 때문에 화가 나 있는 사람이 누구인지** — 그 사람에게 링크를 주면 된다
- 그리고 가설이 이미 틀렸는지에 대한 답. **아무도 대기료 얘기를 안 하면 그게 답이다.** 2주를 기다릴 필요도 없다

### 등업이 필요 없는 곳부터

[화물맨 커뮤니티](https://www.2424-2424.com/community/community_03.php)와 [디스트럭](https://www.dstruck.net)은 카페가 아니라 사이트 게시판이라 등업 절차가 없을 가능성이 있다. **확인은 직접 해야 한다.** 바로 쓸 수 있으면 여기부터 올려서 시계를 일주일 당긴다.

### 일정

```
D-7  카페 가입 + 매일 10분 조사        ← 지금
D+0  등업 완료, 1회차 글             ← 2주 시계 시작
D+14 판정
```

**총 3주다.** 시계는 가입한 날이 아니라 **첫 글을 쓴 날**부터 센다.



## 2. 글이 묻히는 문제 — 같은 글을 다시 올리지 않는다

같은 글을 반복해서 올리면 **광고로 신고당하고 계정이 막힌다.** 그러면 실험 자체가 끝난다.

대신 **다른 글을 쓴다.** 도구는 같아도 글은 매번 달라야 한다.

| 회차 | 시점 | 글의 소재 |
|---|---|---|
| 1 | D+0 | **도구 소개.** "고시 별지 서식 그대로 만들어봤습니다" |
| 2 | D+4 | **정보 글.** "2026 고시에서 대기시간 확인서 서식이 새로 생겼습니다" — 도구는 맨 아래 한 줄 |
| 3 | D+8 | **중간 결과 공유.** "○○분이 써주셨고 이런 점이 불편하다고 하셔서 고쳤습니다" |
| 4 | D+12 | **질문 글.** "대기료 청구, 실제로 받아보신 분 계신가요?" — 도구는 댓글에 |

원칙 셋.
- **채널당 4회를 넘기지 않는다**
- **홍보 글보다 정보 글이 오래 산다.** 2·4번이 1번보다 반응이 좋을 가능성이 높다
- **댓글에 답을 단다.** 댓글 하나가 글을 다시 위로 올린다. 새 글을 쓰는 것보다 싸다

## 3. 무엇을 보고 판정하나

### 숫자 — 구글 시트에 자동으로 쌓인다

| 보는 것 | 어디 | 판정 |
|---|---|---|
| **생성 횟수** | 시트 1 행 수 | **2주 10건 미만 → 중단** |
| 종류별 분포 | 시트 1 B열 | 대기시간이 압도적이면 그게 진짜 문제 |
| 재방문 | 시트 1 C열 | `2-3`·`4+`가 있으면 **한 번 쓰고 마는 도구가 아니다.** 이게 제일 좋은 신호다 |
| **경로** | 시트 1 D열 | `request`는 쌓이는데 `link`가 0 → **화주가 서명을 안 한다는 뜻.** 사업의 전제가 무너진다 |

### 설문 — 시트 2에 쌓인다

| 보는 것 | 판정 |
|---|---|
| **손실액** (`m100`·`m300`) | 이 답이 과반이면 **월 20만원 제품이 성립한다** |
| 손실액 (`none`·`never`) | 과반이면 **돈이 안 되는 문제다.** 접는다 |
| **화주의 서명 태도** (`avoid`) | 많으면 링크만으로는 안 된다. 법 조항을 더 앞세워야 한다 |
| 역할 분포 | 차주가 많고 운송사가 없으면 **고객이 아닌 사람이 쓰고 있다는 뜻** |

### 판정표

| 생성 | 손실액 응답 | 결정 |
|---|---|---|
| 10건 미만 | — | **중단.** 미련 없이 |
| 10건 이상 | `m100`·`m300` 과반 | **계속.** 청구서 기능까지 만든다 |
| 10건 이상 | `none`·`m30` 과반 | 제품은 맞는데 **가격이 안 나온다.** 무료로 남기고 다른 걸 한다 |
| 10건 이상 | 설문 응답 5건 미만 | 판정 불가. **1주 연장하고 설문 문구를 고친다** |

## 4. 가격은 이 실험으로 정하지 않는다

**"얼마면 쓰시겠어요"는 묻지 않는다.** 그 답은 쓸모가 없다. 사람은 가상의 가격에 정직하게 답하지 않는다.

대신 **지금 얼마를 잃고 있는지**를 묻고, 가격은 거기서 역산한다.

```
월 20만원이 정당해지는 조건 = 우리가 되찾아주는 돈이 월 100만원 이상
```

손실액 응답이 `m100` 이상으로 몰리면 그때 **실제 가격 실험**을 따로 한다. 그건 2주 실험의 일이 아니다.

## 5. 이번 2주가 답하지 못하는 것

숨기지 않는다. 아래는 2주 뒤에도 모른다.

- **운송사가 돈을 낼지** — 도구는 무료다. 무료로 쓰는 것과 사는 것은 다르다
- **회수 성공률** — 확인서를 받아내도 화주가 실제로 주는지
- **2028년 이후** — 일몰 뒤에도 수요가 남는지

2주 실험은 **"이 문제가 진짜인가"**까지만 답한다. 그다음 질문은 그다음에 묻는다.
