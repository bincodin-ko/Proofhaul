# Proofhaul 인프라 스택 추천

작성일: 2026-09-15 · 기준: 1인 운영, 인프라 월 상한 $200, 시급 30,000원, 환율 1,400원/$

> **한 줄 결론:** 플랫폼 선택으로 아낄 수 있는 돈보다 **알림톡 발송 비용이 5배 크다.** 인프라는 고객 100명까지 어느 경로든 비슷하고, 고객 1,000명 시점에 5배로 갈린다.

## 1. 워크로드 프로필

```
서비스: 기사가 배송·운송 증빙(사진·서명·인수증)을 올리면 화주·고객이 확인하고 내려받는 서비스
컴퓨트 형태: 혼합 — 요청-응답 + 장시간 작업 3종(PDF 생성, 이미지 변환, LLM 호출)
데이터 형태: 파일·미디어 중심. 업로드보다 다운로드가 많음
트래픽: B2B 업무시간 집중, 배송 마감 시간대 스파이크
지역: 한국 우선
정지 내성: 높음 — 3일 멈춰도 카톡·전화로 임시 처리 가능 → 셀프호스트 허용
내 운영 허용 시간: 월 3시간 (기본값)
LLM: 있음 (기능 미정 — 증빙 사진에서 운송장번호·수량 추출로 가정)
```

**규모 시점 가정** (고객 = 화주사, 화주사당 월 배송 500건)

| 시점 | 월 배송건 | 누적 저장 | 월 egress | LLM 호출 | 알림톡 |
|---|---:|---:|---:|---:|---:|
| 출시 직후 (화주 3사) | 1,500 | 5GB | 10GB | 1,500 | 1,500 |
| 고객 100명 | 50,000 | 300GB | 400GB | 50,000 | 50,000 |
| 고객 1,000명 | 500,000 | 3TB | 4TB | 500,000 | 500,000 |

건당 사진 2장 + 서명 + PDF ≈ 1MB 저장, 화주 열람 3회 가정.

## 2. 비용이 새는 지점

조사 결과 **예상과 다른 그림**이 나왔습니다. 고객 100명 시점의 월 현금 비용 분해:

| 항목 | 월 비용 | 비중 |
|---|---:|---:|
| **알림톡** | $355 | **68%** |
| LLM (Haiku 4.5 + 배치) | $75 | 14% |
| 호스팅 VPS | $48 | 9% |
| 이메일 (Resend) | $20 | 4% |
| 스토리지 R2 | $4 | 1% |
| DB | $0 | 0% |

**인프라 전체가 청구서의 14%입니다.** Vercel을 쓰든 VPS를 쓰든 그 차이는 월 $50~60이고, 알림톡 발송 정책 하나가 월 $355를 좌우합니다.

지목된 함정 (`cost-traps.md` 대조):

1. **#12 알림톡·SMS — 최대 항목.** 배송 건당 수하인 알림 1건 = 건당 10원. 월 5만건이면 50만원. 재시도와 SMS 대체 발송이 붙으면 더 커집니다. **이 서비스의 사업 모델은 알림톡 단가 위에 서 있습니다.**
2. **#11 LLM 토큰 — 2위.** 전 건에 LLM을 돌리면 고객 1,000명에서 월 $750. 배치 API 50% 할인을 이미 반영한 값입니다.
3. **#1 Egress — 구조적으로 막아야 하는 항목.** R2($47)와 S3 서울($566)이 고객 1,000명 시점에 **12배** 차이납니다. 지금은 작아 보이지만 여기서 잘못 고르면 나중에 데이터 이전이 가장 어려운 층입니다.
4. **#3 서버리스 실행 시간.** PDF 생성 + 이미지 변환 + LLM 대기를 서버리스에서 돌리면 대기 시간까지 과금됩니다. 이 프로필에서 **상시 실행 서버가 기본값**인 이유입니다.

R2: 저장 $0.015/GB·월, Class A $4.50/백만, Class B $0.36/백만, **egress 무료**, 무료 티어 10GB + Class A 100만 + Class B 1,000만.

## 4. 추천 스택 (주)

**Vultr 서울 VPS + Coolify + Postgres(같은 박스) + Cloudflare R2 + 자체 인증 + pg-boss 큐**

| 레이어 | 선택 | 이유 |
|---|---|---|
| 호스팅 | Vultr 서울 VPS + Coolify | 장시간 작업 3종이 서버리스에 맞지 않음. 서울 리전으로 기사 앱 업로드 지연 최소 |
| DB | 같은 박스 Postgres | 부품 수 0 증가. 백업은 Coolify → R2 |
| 스토리지 | **Cloudflare R2** | egress $0. 고객 1,000명 시점에 S3 대비 월 $519 차이 |
| 인증 | 자체 (Better Auth + 카카오) | MAU 과금 없음, 사용자 테이블이 내 DB에 |
| 큐·워커 | pg-boss (Postgres 큐) | PDF·이미지·LLM을 요청-응답에서 분리. Redis 불필요 |
| LLM | Claude Haiku 4.5 + 배치 API | 추출 작업에 충분한 최소 티어. 배치 50% 할인 |
| 알림 | 알림톡 공식 딜러사 | 건당 10원, 월 10만건 초과 시 8원 |
| 앞단 | Cloudflare Free (DNS·CDN·WAF) | 무료, 서울 PoP |

### 월 총액 (인프라만 — 알림톡·LLM 제외)

| 시점 | 현금 | 운영 시간 | 시간 비용 | 합계 | $200 상한 |
|---|---:|---:|---:|---:|:--:|
| 출시 직후 | $12 | 4.3h | $92 | $104 | OK |
| 고객 100명 | $72 | 4.3h | $92 | **$164** | OK |
| 고객 1,000명 | $301 | 4.3h | $92 | $393 | 초과 |

### 알림톡·LLM 포함 전체

| 시점 | 현금 | 합계(시간 포함) |
|---|---:|---:|
| 출시 직후 | $25 | $145 |
| 고객 100명 | $502 | $622 |
| 고객 1,000명 | $4,601 | $4,721 |

**고객 100명 시점에 인프라는 상한 안에 들어오지만 알림톡이 상한을 혼자 넘깁니다.** 이건 인프라 문제가 아니라 단가 구조 문제이므로, 객단가에 반영하거나 발송 정책을 바꿔야 합니다. 화주사당 월 500건 × 10원 = 5,000원이 원가이므로, 객단가가 월 5만원이면 알림톡 원가율 10%입니다 — 감당 가능한 수준이지만 **객단가 산정 시 반드시 포함해야 합니다.**

### 이 추천이 틀리는 조건

1. **배송 건당 알림톡이 2건을 넘으면** — 인프라 최적화는 의미가 없어집니다. 발송 정책(수하인 알림을 화주 선택 옵션으로)부터 다시 짜야 합니다.
2. **화주가 월별 정산용으로 증빙을 일괄 ZIP 다운로드하면** — egress가 가정치 4TB를 크게 넘습니다. R2 선택은 더 중요해지지만 VPS 대역폭(2TB 포함)도 재계산이 필요합니다.
3. **내 운영 시간이 월 2시간 미만이어야 하면** — 아래 대안으로 가십시오. 고객 100명까지는 두 경로의 총비용이 사실상 동률($164 vs $164)입니다.
4. **B2B 계약에 개인정보 국내 보관 조항이 들어오면** — R2(해외 리전)를 재검토해야 합니다. 배송 증빙에는 수하인 이름·주소·연락처가 들어가므로 실제로 발생할 수 있는 조건입니다.

### 가장 큰 비용 함정과 방어책

**알림톡.** 방어책 세 가지를 순서대로:
1. 발송 트리거를 "화주가 켠 경우"로 제한 — 기본 꺼짐
2. 실패 시 SMS 자동 대체 발송을 기본으로 켜지 않기 (단가가 몇 배)
3. 월 10만건 넘는 시점에 딜러사 단가 재협상 (10원 → 8원, 월 $71 절감)

인프라 쪽 함정은 **R2와 LLM 모두 지출 상한 설정이 불가**하다는 점입니다. 알림만 걸 수 있으므로 일 단위 알림을 첫 주에 설정하십시오.

## 5. 대안 스택 — 관리형

**Vercel Pro (또는 Cloudflare Workers) + Supabase Pro 서울 + R2 + 별도 워커 머신(Fly.io)**

| 시점 | 현금 | 운영 시간 | 합계 |
|---|---:|---:|---:|
| 출시 직후 | $45 | 1.5h | $77 |
| 고객 100명 | $132 | 1.5h | **$164** |
| 고객 1,000명 | $1,575 | 1.5h | $1,607 |

> 위 표는 스토리지를 S3 서울로 잡은 값입니다. **R2로 바꾸면 고객 1,000명 시점이 $1,575 → $1,056으로 떨어집니다.** 관리형으로 가더라도 파일만은 R2에 두십시오.

**이걸 고를 사람:** 운영 시간을 월 1.5시간 밑으로 눌러야 하고, 고객 1,000명에 도달하기 전에 매각·전환할 계획이거나, 서버 관리 자체가 스트레스인 경우. 고객 100명까지는 주 스택과 총비용이 동률이므로 **초기 단계에서는 이게 틀린 선택이 아닙니다.**

**단, 순수 Vercel 단독은 이 워크로드에 맞지 않습니다.** PDF 생성·이미지 변환·LLM 대기를 서버리스 함수에서 돌리면 실행 시간 과금이 붙는데, 위 표에는 그 항목이 **반영되어 있지 않아 실제로는 더 비쌉니다.** 관리형으로 가더라도 장시간 작업은 별도 상시 머신으로 빼야 합니다.

| 층 | 언제 옮기나 | 어디로 | 이전 난이도 |
|---|---|---|---|
| 호스팅 | VPS CPU 한계 | 상위 플랜 → 베어메탈 | 쉬움 (Docker) |

| 스토리지 | — | **옮길 일 없음** | R2는 S3 호환이라 탈출도 쉬움 |

데이터 층 세 개(DB·스토리지·인증)를 전부 표준 위에 올렸기 때문에, 이 스택은 **어느 방향으로도 빠져나갈 수 있습니다.** 이게 관리형 BaaS에 전부 맡기는 것과의 핵심 차이입니다.

## 7. 사지 말아야 할 것

- **유료 APM (Datadog, New Relic)** — 이 규모에서 Sentry Free + UptimeRobot으로 충분
- **AWS S3 (서울)** — egress 과금. 이 서비스에 정확히 맞지 않는 선택
- **MAU 과금 인증 (Clerk, Auth0)** — 기사 계정이 무료로 많이 생기는 구조
- **멀티리전·쿠버네티스·전용 DB 인스턴스** — 1인 규모에서 운영 시간과 비용 양쪽에서 손해
- **Vercel 좌석 추가** — 외주 개발자 한 명 초대가 월 $20
- **Hetzner** — 2026년 인상 + 서울 리전 없음

## 8. 첫 주에 할 일

1. **R2·LLM 지출 알림 설정** (일 단위). 둘 다 상한 설정이 불가하므로 알림이 유일한 방어선
2. **알림톡 발송 정책 확정** — 배송 건당 몇 건 보낼지가 사업 모델 전체를 좌우. 딜러사 2~3곳 단가 견적
3. **Vultr 서울 + Coolify + Postgres** 세팅, Coolify 백업을 R2로 연결하고 **복구를 한 번 실제로 해보기**
4. **이미지는 업로드 시점에 리사이즈해 저장** — 변환 과금을 원천 차단
5. **PDF·LLM은 pg-boss 큐 + 워커로** 처음부터 분리. 나중에 옮기려면 API 구조를 다시 짜야 함
