# 프로필 채우기 질문

레포가 없거나 코드만으로 채워지지 않는 칸이 있을 때 쓴다. **전부 묻지 않는다.** 대화 맥락과 레포에서 이미 답이 나온 건 건너뛰고, 비어 있는 칸 중 스택 선택을 바꾸는 것만 묻는다. 보통 3~5개면 충분하다.

질문할 때는 사용자가 숫자를 모른다는 전제로 **보기를 준다.** "월 요청 수가 얼마나 되나요?"는 답할 수 없지만 "고객 한 명이 하루에 몇 번 정도 들어오나요 — 한두 번 / 업무 중 계속 / 자동화로 수백 번?"은 답할 수 있다.

## 1. 서비스가 무엇을 하는가 (한 줄)
누가, 무엇을 하려고, 어떤 화면을 여는가. 이 한 줄에서 컴퓨트·데이터 형태의 절반이 나온다.

## 2. 데이터 형태 — 스택을 가장 크게 가르는 질문
- 사용자가 올리는 것이 있는가? 문서(PDF·엑셀) / 사진 / 영상 / 없음
- 있다면 고객 한 명이 한 달에 대략 얼마나 올리고, **얼마나 다시 내려받는가.** 내려받기가 많으면 egress가 청구서의 중심이 된다
- 데이터가 표(관계형)로 정리되는가, 자유로운 문서인가

## 3. 컴퓨트 형태
- 무거운 작업이 있는가: PDF 생성, 이미지 변환, 영상 처리, 크롤링, LLM 호출 (응답 대기 시간이 길다)
- 실시간이 필요한가: 채팅, 동시 편집, 라이브 대시보드
- 정해진 시간에 도는 작업이 있는가 (매일 새벽 집계, 매주 리포트 발송)

## 4. 트래픽 모양
- 처음 3개월 예상 사용자 수 — 정확할 필요 없음, 10명 / 100명 / 1,000명 단위
- 사용 패턴: 업무시간에만 (B2B) / 24시간 고르게 / 마케팅·바이럴로 튄다
- 고객 한 명이 하루에 몇 번 들어오는가: 한두 번 / 업무 중 계속 / 자동화(API)로 수백 번

## 5. 한국 조건
- 사용자 대부분이 한국인가? (서울 리전 필요성)
- 카카오·네이버 로그인이 필요한가?
- 알림톡·문자 발송이 있는가? 월 몇 건?
- 개인정보를 해외 서버에 두어도 되는가 (B2B 계약서에 국내 보관 조항이 있는 경우가 있다)

## 6. 정지 내성 (solo-biz-idea-finder와 같은 질문)
> 서비스가 3일 멈추면 고객에게 무슨 일이 생기는가?
- 아무 일도 안 생김 / 잠시 예전 방식으로 돌아감 → 셀프호스트 허용, 비용 최우선
- 그날 업무가 멈추거나 돈·법적 문제가 생김 → 관리형 우선, 비용 2순위

## 7. 내 운영 허용 시간과 시급
- 한 달에 인프라 운영에 몇 시간까지 쓸 수 있는가 (기본 가정: 3시간)
- 내 시간을 얼마로 치는가 (기본 가정: 3만원/시간). 이 값이 관리형 vs 셀프호스트를 가른다

## 8. 이미 쓰고 있거나 익숙한 것
- 이미 계정·크레딧이 있는 서비스 (AWS Activate, GCP 크레딧, Cloudflare 유료 등)
- 익숙한 것과 낯선 것 — 낯선 스택의 학습 시간도 운영 시간에 포함된다

## 9. LLM 사용 여부
- 어느 기능에서, 고객 한 명이 한 달에 몇 번, 입력 길이는 대략 얼마나 (짧은 질문 / 문서 한 개 / 문서 여러 개)
- 이게 있으면 인프라보다 LLM 원가가 먼저 200달러를 뚫는 경우가 많다
